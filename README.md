# StatJack
A TikTok-Filter / Minigame based on Blackjack played with the base stats of the original Pokémon

## Game
The game is a simplified version of blackjack. A round starts with the game picking a random stat (HP, Attack, Defense, etc.). Each card draw draws one of the 151 original Pokémon and adds its base value of the selected stat to the player's (user/dealer) score. Due to the numerical difference between french playing cards and Pokémon stats, the goal of the game is to come as close as possible to 500 (instead of blackjack's 21)

## Implementation
I am using TikTok's offical effect studio "Effect House", heavily using TypeScript Component-scripts.
